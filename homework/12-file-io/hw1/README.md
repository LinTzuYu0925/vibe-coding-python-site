# 分數檔加總（傳統題）

老師把全班的分數存在 `scores.txt`，一行一個分數。寫一個程式讀這個檔案，算出有幾筆、總分多少。

## 規格

- 讀同一個資料夾裡的 `scores.txt`（記得 `encoding="utf-8"`）。這題**不用** `input()`。
- 每行是一個 0 到 100 的整數，前後可能有空格。
- **空白行**跳過，不算一筆。
- 印出一行：`共 N 筆，總分 T`。檔案是空的時候印 `共 0 筆，總分 0`。

例如 `scores.txt` 的內容是：

```
80
95
70
```

印出：

```
共 3 筆，總分 245
```

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

會用到單元 12 的 `with open(...) as f:`、`for line in f:`、`.strip()`、`int()`。

在自己電腦上執行時，先在 `.py` 旁邊建一個 `scores.txt`，貼上上面的內容。
