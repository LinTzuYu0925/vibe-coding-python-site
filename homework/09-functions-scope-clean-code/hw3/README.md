# 購物車結帳（傳統題）

網路商店要計算購物車的應付金額。

## 規格

- 輸入：每行一件商品的金額（0 以上的整數），最後一行是 `結束`。
- 依序算出：
  - **小計**：所有金額加起來。
  - **折扣後**：小計滿 1000（剛好 1000 也算）打 9 折，小數無條件捨去；不滿 1000 不打折。
  - **運費**：折扣後金額滿 500（剛好 500 也算）免運，也就是 0 元；不滿 500 收 60 元。**小計是 0 時不收運費。**
  - **應付**：折扣後加運費。
- 印出四行：

```
小計 1111
折扣後 999
運費 0
應付 999
```

## 範例

| 輸入（每行一個） | 應該印出（四行，用「／」隔開） |
|---|---|
| 1111、結束 | 小計 1111／折扣後 999／運費 0／應付 999 |
| 200、100、結束 | 小計 300／折扣後 300／運費 60／應付 360 |
| 結束 | 小計 0／折扣後 0／運費 0／應付 0 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

請**至少寫兩個函式**，例如 `discount(subtotal)` 和 `shipping(total)`：丟進去一個數字，`return` 一個數字。函式裡不要 `print`，讀資料和印出放在函式外面。網頁只檢查輸出，有沒有拆成函式要自己把關。

不用 AI 也能完成。卡住時，先在紙上算 1111 這一筆；「小數無條件捨去」可以用 `//`：`1111 * 9 // 10`。
