# 略過壞資料的加總（抓錯題）

感測器傳來一串資料，有些是壞的。程式要把**所有好的資料**加起來，壞的資料跳過並計數。

## 規格

- 輸入一行：用空格隔開的資料，可能什麼都沒有。
- 整數算好資料，其他都是壞資料。
- 印出 `總和 X，略過 Y 個`。

| 輸入 | 應該印出 |
|---|---|
| `1 2 3` | 總和 6，略過 0 個 |
| `1 2 abc` | 總和 3，略過 1 個 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面的例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`input().split()` 把一行從空格切開，這個寫法課程沒有教。遇到錯誤時，程式會**直接跳到** `except`，`try` 裡後面的程式都不會做（單元 10）。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`try` 應該放在 `for` 的外面，還是裡面？
