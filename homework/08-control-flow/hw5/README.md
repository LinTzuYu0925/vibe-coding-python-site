# 提款機（傳統題）

帳戶一開始有 **1000 元**。輸入一連串的交易，程式要處理每一筆，還要防止有人一直亂試。

## 規格

- 輸入：每行一個整數，最後一行是 `結束`。正數是存款，負數是提款。
- 每筆印一行：
  - 存款：存進去，印 `餘額 X`。
  - 提款，餘額夠：扣掉（**可以提到剛好 0 元**），印 `餘額 X`。
  - 提款，餘額不夠：不扣錢，印 `餘額不足`。
  - 輸入 0：印 `沒有變動`。
- **連續 3 次**餘額不足：多印一行 `帳戶鎖定`，並且立刻停止，後面的交易都不處理。
  - 成功的存款或提款，會把連續次數歸零。
  - 輸入 0 **不會**歸零，也不算一次失敗。
- 最後印一行：`最後餘額 X`（鎖定時也要印）。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `500`、`-200`、`結束` | 餘額 1500／餘額 1300／最後餘額 1300 |
| `-2000`、`100`、`結束` | 餘額不足／餘額 1100／最後餘額 1100 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

不用 AI 也能完成。卡住時，先在紙上寫下每一行讀入以後的「餘額」和「連續失敗次數」。
