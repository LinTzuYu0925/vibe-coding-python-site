# Vibe Coding with Python：範例程式

課程投影片：<https://LinTzuYu0925.github.io/vibe-coding-python-site/>

每個單元一個資料夾，範例程式在該資料夾的 `materials/` 裡，檔名與投影片上標示的相同。

## 下載

```
git clone --depth 1 https://github.com/LinTzuYu0925/vibe-coding-python-site.git
```

之後要取得更新：進入 `vibe-coding-python-site` 資料夾，執行 `git pull`。

## 執行範例

在終端機進入範例所在的 `materials` 資料夾，再執行：

```
python 檔名.py
```

範例讀取的資料檔（例如 `students.csv`）放在同一個資料夾，請在該資料夾裡執行。

## 作業

`homework/<單元>/hwN/` 是作業的題目（`README.md`）、起始程式（`starter.py`）與範例（`tests/public.txt`）。
在線上練習頁面可以直接執行與檢查：<https://LinTzuYu0925.github.io/vibe-coding-python-site/oj/>
