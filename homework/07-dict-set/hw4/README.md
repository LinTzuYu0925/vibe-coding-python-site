# 英文小字典（傳統題）

寫一個小字典：輸入英文單字，印出中文。

| 英文 | 中文 |
|---|---|
| apple | 蘋果 |
| book | 書 |
| cat | 貓 |
| dog | 狗 |
| egg | 蛋 |

## 規格

- 輸入一行：英文單字。
- 字典裡有的話，印出中文；沒有的話，印 `查無此字`。
- 要**完全一樣**才算查到。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `apple` | 蘋果 |
| `zebra` | 查無此字 |

## 你的任務

程式框是空的，從第一行開始自己寫：把表格寫成 dict，用 `.get()` 查。這題**不用** `if`。按「檢查範例」。

不用 AI 也能完成。
