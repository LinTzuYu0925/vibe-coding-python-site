# 最長連續打卡（測資題）

健身 App 用一行文字記錄每天有沒有運動：`O` 是有，`X` 是沒有。App 要顯示「最長連續運動了幾天」。

## 規格

- 輸入一行，只有大寫 `O` 和 `X`，長度不限，**也可能是空的**（還沒有任何紀錄）。
- 印出最長的連續 `O` 有幾個。沒有任何 `O` 時印 `0`。

| 輸入 | 應該印出 | 說明 |
|---|---|---|
| `XOOOX` | 3 | 中間那段 OOO |
| `XXOOX` | 2 | 那段 OO |

## 你的任務

這次**不用寫程式**。網頁裡藏了 5 個「寫錯的版本」，都是寫迴圈時最常見的錯：上面兩個例子它們全都答對。

在下方表格設計檢查案例（一組輸入，加上你算出來的正確答案），按「檢查」，把 5 個寫錯的版本都抓出來。

想不出來時，想想這些位置：最前面、最後面、什麼都沒有、全部都一樣。

> 這就是單元 08 說的「邊界」。AI 寫的迴圈最常錯在這裡，而一般的輸入抓不到。
