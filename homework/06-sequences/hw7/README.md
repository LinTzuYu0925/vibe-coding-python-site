# 錄取分數線（黑箱題）

學校依照分數高低錄取學生，錄取的人數和報名人數有關。

輸入：

```
90 70 85 60 75 65 80 55 95 50
```

印出：

```
錄取 3 人，最低分 85
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 錄取**幾成**的人？（10 個人的時候最好算。）
   - 人數算出來有小數時（例如 4 個人），是進位還是捨去？只有 1 個人呢？
   - 錄取名額最後一位有**同分**的人，也會一起錄取嗎？人數會超過名額嗎？
   - 輸入的順序會影響結果嗎？`9` 和 `100` 會排對嗎？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
