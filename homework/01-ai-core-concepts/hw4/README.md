# 折扣碼結帳（黑箱題）

購物網站有三種折扣碼：`SAVE10`、`MINUS50`、`HALF`。名字沒有說完整的規則。

輸入金額和折扣碼（各一行）：

```
1000
SAVE10
```

印出：

```
應付 900
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 三種折扣碼各折多少？折完有小數時怎麼處理？
   - `MINUS50` 有沒有**最低消費**？剛好那個金額可以用嗎？不夠時印什麼？
   - `HALF` 能折的錢有**上限**嗎？上限是多少？
   - 折扣碼打**小寫**、前後多打空格，還算數嗎？
   - 折扣碼**打錯**或**沒打**時，分別印什麼？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI。可以貼到免費的 ChatGPT 或 Claude 網頁版。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
