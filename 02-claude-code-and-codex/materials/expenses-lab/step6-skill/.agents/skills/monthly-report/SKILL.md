# 記帳月報

## 步驟
1. 讀取 `expenses.csv`。使用者沒有指定月份時，用資料中最新的月份。
2. 只計算該月份的資料。
3. 分類依照 `docs/categories.md`。
4. 依下面的格式寫成 `reports/月份.md`（例如 `reports/2026-10.md`），並把全文貼在對話中。
5. 最後一行一定要寫：「請自己核對總金額。」

## 格式
```
# 2026-10 記帳月報

- 筆數：（幾筆）
- 總金額：（元）
- 最大的一筆：（日期 項目 金額）

| 分類 | 金額 |
|---|---|
| 餐飲 | （元） |

請自己核對總金額。
```

## 不要做的事
- 不要修改 `expenses.csv`。
- 金額不要四捨五入，也不要加上小數點。
