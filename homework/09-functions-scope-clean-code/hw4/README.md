# 成績等第（傳統題）

輸入分數，印出等第。

| 分數 | 等第 |
|---|---|
| 90 以上 | A |
| 80～89 | B |
| 70～79 | C |
| 60～69 | D |
| 60 以下 | F |

## 規格

- 輸入一行：0～100 的整數。
- 印出一行：`等第 X`。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `95` | 等第 A |
| `72` | 等第 C |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

請寫一個函式 `grade(score)`：丟進去分數，`return` 等第；函式裡不要 `print`。網頁只檢查輸出，有沒有寫成函式要自己把關。

不用 AI 也能完成。
