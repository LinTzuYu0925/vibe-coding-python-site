# 密碼強度檢查（黑箱題）

網站註冊時會檢查密碼強度。它**不會告訴你規則**，只回答結果。

輸入：

```
Abc12345
```

印出：

```
強度 中
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 強度看的是哪些**條件**？總共幾個？（試試只改一個地方：加一個大寫、加一個符號、加長。）
   - 滿足幾個條件算「強」？幾個算「中」？
   - 長度的分界是幾個字？**剛好那個長度**算有達到嗎？
   - 密碼裡有 `password` 這個字（大小寫都試試），會怎樣？
   - 密碼裡有**空格**會怎樣？什麼都沒輸入呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI。可以貼到免費的 ChatGPT 或 Claude 網頁版。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
