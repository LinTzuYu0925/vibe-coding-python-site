# 工作天計算（黑箱題）

專案經理輸入開始日期和結束日期（各一行），程式算出這段時間有幾個工作天。

輸入：

```
2026-03-02
2026-03-06
```

印出：

```
工作天 5 天
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - **開始和結束那兩天**都算嗎？同一天呢？
   - 週六、週日算嗎？
   - 有沒有哪個**平日**也不算？試試 `2025-10-10`（週五）和 `2027-01-01`（週五）這兩個節日。
   - 跨月、跨年、閏年的 2 月，算得對嗎？
   - 結束日期早於開始日期會怎樣？日期不存在或不是日期呢？這兩種訊息一樣嗎？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
