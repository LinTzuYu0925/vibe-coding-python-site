# 影片長度換算（抓錯題）

影片網站把影片長度從「分鐘」換成「幾小時幾分」。

## 規格

- 輸入一行：影片長度，0 以上的整數（分鐘）。
- 印出 `X 小時 Y 分`，`Y` 一定小於 60。

| 輸入 | 應該印出 |
|---|---|
| `125` | 2 小時 5 分 |
| `60` | 1 小時 0 分 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`round(數字)` 是**四捨五入**到整數；`/` 是一般除法，`%` 是餘數（單元 05 教過）。
2. 在表格的「輸入」欄打一個分鐘數，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：應該用哪一個運算子取代 `round(minutes / 60)`？

> 想想看：100 分鐘是 1.67 小時。四捨五入會變成幾小時？
