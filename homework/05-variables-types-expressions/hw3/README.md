# 找零錢（傳統題）

自動販賣機要找錢，硬幣有 **50 元、10 元、5 元、1 元**。它總是先用大的硬幣，讓硬幣的枚數最少。

## 規格

- 輸入一行：要找的錢（0 以上的整數，單位：元）。
- 印出四行，依序是 50 元、10 元、5 元、1 元各幾枚：

```
50 元 1 枚
10 元 3 枚
5 元 1 枚
1 元 2 枚
```

（這是找 87 元：50 + 10 × 3 + 5 + 1 × 2 = 87。）

## 範例

| 輸入 | 應該印出（四行，用「／」隔開） |
|---|---|
| `87` | 50 元 1 枚／10 元 3 枚／5 元 1 枚／1 元 2 枚 |
| `0` | 50 元 0 枚／10 元 0 枚／5 元 0 枚／1 元 0 枚 |
| `49` | 50 元 0 枚／10 元 4 枚／5 元 1 枚／1 元 4 枚 |

## 你的任務

下方程式框已經放好 `starter.py`：讀入和 50 元的部分寫好了。照同樣的方法，用 `//`（整除，取商）和 `%`（餘數）補上 10 元、5 元、1 元，再把它們印出來，按「檢查範例」。

不用 AI 也能完成。卡住時，先在紙上用 87 算一次：每一步「拿幾枚」、「還剩多少」。
