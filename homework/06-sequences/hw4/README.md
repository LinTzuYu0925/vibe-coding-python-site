# 最高和最低（傳統題）

輸入一行分數，印出最高分、最低分和它們的差距。

## 規格

- 輸入一行：至少 1 個整數，用空格隔開。
- 印出一行：`最高 A，最低 B，差距 C`。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `3 9 2` | 最高 9，最低 2，差距 7 |
| `5 5` | 最高 5，最低 5，差距 0 |
