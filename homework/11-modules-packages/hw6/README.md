# 異常值偵測（黑箱題）

機器學習之前，常常要先找出「特別不一樣」的資料。這個工具讀入一行數字，指出哪些是異常值。

輸入：

```
10 12 11 13 10 12 11 60
```

印出：

```
平均 17.4
標準差 17.25
異常值 [60]
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 這個標準差是 `statistics.stdev` 還是 `statistics.pstdev`？（自己用 Python 算算看，比對黑箱。）
   - 離平均**多遠**才算異常？是 2 個標準差、3 個，還是別的？試著設計一組輸入分辨它們。
   - **太小**的值也算異常嗎？
   - 異常值的**順序**是照什麼排的？重複的會印兩次嗎？
   - 全部一樣時會怎樣？只有 1 個數字、什麼都沒輸入呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
