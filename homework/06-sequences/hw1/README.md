# 房價代表價（黑箱題）

房屋網站列出一個社區最近成交的幾間房子價格（萬元），再顯示一個「代表價」，讓買家知道這裡的房子大概多少錢。

輸入一行價格（用空格隔開），例如 `1200 800 950`，它印出：

```
代表價 950.0
```

這**不是平均**：1200、800、950 的平均是 983.3。

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入各種價格，找出「代表價」是怎麼選出來的。試試看：
   - 把同樣幾個價格**換個順序**輸入，答案會變嗎？
   - 放進一間**特別貴**的房子（例如 `500 520 3000`），代表價會被拉高嗎？
   - 價格有**偶數個**時（例如 4 個），中間沒有剛好一個，它怎麼辦？
   - 只有 **1 個**價格呢？
2. **寫規格**：用單元 06 學的詞（排序、索引、`len()`）把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 為什麼不用平均？想想一個社區裡有一棟豪宅時，平均會變成怎樣。單元 14 的機器學習也常遇到這種「特別大的值」。
