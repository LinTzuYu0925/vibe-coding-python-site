點「看投影片」開啟該單元（方向鍵換頁）。投影片上標示 materials/… 的檔名可以直接點開看程式碼。有「線上練習」的單元，可以在瀏覽器裡直接執行 Python 檢查作業（全部練習）。

一次下載全部範例

在終端機貼上這行，會在目前資料夾建立 vibe-coding-python-site 資料夾：

git clone --depth 1 https://github.com/LinTzuYu0925/vibe-coding-python-site.git

之後要取得更新：進入該資料夾，執行

git pull
