# 不會當掉的計算機（傳統題）

寫一個計算機，一行算一題。使用者會打錯，但程式**不能當掉**，要說清楚錯在哪裡，然後繼續算下一題。

## 規格

- 輸入：每行一題，格式是 `數字 運算子 數字`，用空格隔開；最後一行是 `結束`。
- 運算子只有 `+`、`-`、`*`、`/`，數字可以有小數或負號。
- 每題印一行，**依下面的順序**檢查，碰到第一個錯誤就印出來：
  1. 用空格切開以後不是剛好 3 段（包含空白行）：印 `格式錯誤`。
  2. 第一段或第三段不是數字：印 `不是數字`。
  3. 運算子不是上面四個：印 `不支援的運算`。
  4. 除以 0：印 `不能除以 0`。
  5. 沒有錯誤：印出答案，**一律保留兩位小數**，例如 `7.00`。
- 最後一行印 `成功 N 筆，失敗 M 筆`。

## 範例

| 輸入（每行一個） | 應該印出（用「／」隔開） |
|---|---|
| `3 + 4`、`結束` | 7.00／成功 1 筆，失敗 0 筆 |
| `5 / 0`、`abc + 1`、`1 +`、`結束` | 不能除以 0／不是數字／格式錯誤／成功 0 筆，失敗 3 筆 |
| `結束` | 成功 0 筆，失敗 0 筆 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

切開一行的寫法課程沒有教，這裡直接告訴你：`"3 + 4".split()` 得到 `["3", "+", "4"]`，多打的空格不會多切出東西，空白行得到 `[]`。其他都是教過的：`while`、`if`、`float()`、`try`／`except`。

不用 AI 也能完成。卡住時，先只處理 `3 + 4`，再一個一個加上面的檢查。只接該接的錯誤（`except ValueError`），不要用 `except:` 全接。
