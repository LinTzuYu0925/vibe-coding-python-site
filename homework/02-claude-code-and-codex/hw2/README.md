# 依月份篩選（測資題）

月報功能要先判斷：一筆記帳的日期，是不是落在要查詢的月份裡。

## 規格

- 輸入一行：**記帳日期**和**查詢月份**，中間空一格，例如 `2026-10-05 2026-10`。
- 記帳日期一定是 `年-月-日`，月和日都是兩位數（`2026-01-05`）。
- 查詢月份是 `年-月`，月份**可以寫一位數或兩位數**：`2026-1` 和 `2026-01` 都代表 2026 年 1 月。
- 日期屬於該月，印出 `是`；否則印出 `否`。

| 輸入 | 應該印出 |
|---|---|
| `2026-10-05 2026-10` | 是 |
| `2025-09-30 2026-10` | 否 |

## 你的任務

這次**不用寫程式**。這個網頁裡藏了 4 個「寫錯的版本」，都是 AI 真的常犯的錯：一般的輸入都答對，只有特定輸入才會出錯。

你要設計**檢查案例**（一組輸入，加上你算出來「應該印出」的答案），把它們全部抓出來：

1. 在下方表格每列填一組檢查案例。
2. 按「檢查」。網頁會告訴你：每一列的答案你算得對不對，以及一共抓到幾個寫錯的版本。
3. 抓不完就再想：哪些輸入「看起來差不多、但答案不一樣」？

> 驗證 AI 寫的程式，靠的就是這種檢查案例。只試一般情況，AI 的程式幾乎都會過。
