# 平均每筆花費（抓錯題）

記帳小工具要算平均每筆花多少錢。

## 規格

- 輸入一行：至少 1 個整數金額，用空格隔開。
- 印出 `平均 X`，`X` 保留一位小數。

| 輸入 | 應該印出 |
|---|---|
| `10 20` | 平均 15.0 |
| `65 31 30` | 平均 42.0 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面的例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`//` 和 `/` 不一樣：`7 // 2` 是 3，`7 / 2` 是 3.5。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：哪一個符號要換掉？
