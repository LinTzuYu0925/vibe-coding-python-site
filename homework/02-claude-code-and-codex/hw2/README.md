# 依月份篩選（抓錯題）

月報功能要先判斷：一筆記帳的日期，是不是落在要查詢的月份裡。

## 規格

- 輸入一行：**記帳日期**和**查詢月份**，中間空一格，例如 `2026-10-05 2026-10`。
- 記帳日期一定是 `年-月-日`，月和日都是兩位數（`2026-01-05`）。
- 查詢月份是 `年-月`，月份**可以寫一位數或兩位數**：`2026-1` 和 `2026-01` 都代表 2026 年 1 月。
- 日期屬於該月，印出 `是`；否則印出 `否`。

| 輸入 | 應該印出 |
|---|---|
| `2026-10-05 2026-10` | 是 |
| `2025-09-30 2026-10` | 否 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`date.startswith(query)` 的意思是「日期的**開頭**是不是和查詢月份一模一樣」。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。

> 想想看：哪些輸入「看起來開頭一樣，其實是不同月份」？反過來，哪些「開頭不一樣，其實是同一個月」？
