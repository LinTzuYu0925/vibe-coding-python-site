# 檔名整理工具（黑箱題）

同學存檔時常常取出奇怪的檔名，害 Python 找不到檔案。這個工具把一行文字整理成安全的檔名。

輸入：

```
My Homework
```

印出：

```
my_homework.py
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 英文**大寫**會變成什麼？**空格**會變成什麼？前後的空格呢？中間連續兩個空格呢？
   - 沒有打副檔名時，會自動加上什麼？已經有副檔名（例如 `.txt`）時呢？
   - 檔名**開頭是數字**時，會發生什麼事？（想想單元 04 說的檔名建議。）
   - 什麼都沒打時，會給什麼檔名？中文檔名呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
