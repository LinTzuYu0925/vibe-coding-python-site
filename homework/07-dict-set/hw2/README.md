# 兩天活動總人數（抓錯題）

社團辦兩天活動，報名表是志工手動打的，同一個人可能被打不只一次。主辦人要知道兩天總共有幾個**不同的人**。

## 規格

- 輸入一行：週六名單、一條 `/`、週日名單。名字之間用空格隔開，名單可以是空的。
- 印出 `兩天都來 A 人，總共 B 人`。`A`、`B` 算的都是**不同的人**：同一個名字不管打幾次，都只算一個人。

| 輸入 | 應該印出 |
|---|---|
| `Amy Ben / Ben Cara` | 兩天都來 1 人，總共 3 人 |
| `Amy / Ben` | 兩天都來 0 人，總共 2 人 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`input().split("/")` 把一行從 `/` 切成兩段，`.split()` 再把一段文字從空格切成 list；這兩個寫法課程沒有教，知道它們切出什麼就好。`&` 是兩邊都有（交集，單元 07 備用頁）。
2. 在表格的「輸入」欄打一組名單，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`total` 那一行應該怎麼改？
