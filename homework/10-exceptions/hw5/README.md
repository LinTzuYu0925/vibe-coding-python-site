# 訂單匯入檢查（黑箱題）

商店要把一批訂單匯入系統。資料是人工打的，可能有各種錯誤。程式要指出**第幾行**、**錯在哪裡**，並且算完所有正確的訂單。

輸入：

```
紙箱,30,2
膠帶,abc,1
結束
```

印出：

```
第 2 行：不是整數
成功 1 筆，失敗 1 筆
總金額 60
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 總共有**幾種**錯誤訊息？（試試少一欄、多一欄、沒寫品名、單價是文字、單價或數量是 0、是負數。）
   - 一行同時有**兩種**錯誤時，印哪一個？試出檢查的順序。
   - **空白行**算錯誤嗎？它占不占行號？
   - 行號從第幾開始算？
   - 欄位前後多打空格算錯嗎？小數呢？
   - 全部都錯，或一筆都沒有時，最後兩行印什麼？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
