# 成績 Dataset（傳統題）

把學生的姓名和分數收進一個 `Dataset` 類別，讓它自己算人數、平均、最高分。同一個人加入兩次時，用**新的**分數（例如補考）。

## 規格

寫一個類別 `Dataset`：

- `__init__(self)`：建立時沒有任何學生。
- `add(self, name, score)`：加入一位學生。姓名先去掉前後空格；同名的人已經在裡面，就**改成新的分數**，不多算一人。
- `count(self)`：**回傳**人數。沒有學生時回傳 `0`。
- `average(self)`：**回傳**平均（不要先四捨五入）。
- `best(self)`：**回傳**最高分的姓名和分數兩個值，例如 `return name, score`。同分時，回傳**最先加入**的那位（改過分數的人，還是算他第一次加入的位置）。

沒有學生時，網頁只會呼叫 `count()`，不會呼叫 `average()`、`best()`。

只寫類別就好，**不要寫 `input()`，也不要寫主程式**。

## 網頁怎麼檢查

網頁會在你的程式後面接上一段測試程式，像這樣使用你的類別：

```python
other = Dataset()
other.add("路人", 1)     # 另一個 Dataset，data 不能被它影響
data = Dataset()
data.add("小明", 70)
data.add("小華", 92)
data.add("小美", 83)
data.count()             # 應該回傳 3
data.average()           # 應該回傳 81.666…（網頁取到小數第二位：81.67）
data.best()              # 應該回傳 ("小華", 92)
```

測試程式把每個回傳值印出來，再和「應該印出」比對。方法裡用 `print` 印出答案、沒有 `return`，會被抓到。完整的測試程式在下方「看看測試程式」。
