# 提款機（黑箱題）

提款機讀入一連串交易：正數是存款，負數是提款。它還有一些防止亂試的規則，說明書上沒有寫。

輸入：

```
300
-100
結束
```

印出：

```
餘額 1300
餘額 1200
最後餘額 1200
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 帳戶一開始有**多少錢**？
   - 提的錢比餘額多時，會怎樣？可以提到**剛好 0 元**嗎？
   - 一直提不出來，會發生什麼事？**連續幾次**？發生之後，後面的交易還會處理嗎？
   - 中間成功存款或提款一次，次數會重新算嗎？輸入 `0` 呢？
   - 輸入 `0` 會印什麼？最後一行在各種情況都會印嗎？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
