# 最長連續打卡（抓錯題）

健身 App 用一行文字記錄每天有沒有運動：`O` 是有，`X` 是沒有。App 要顯示「最長連續運動了幾天」。

## 規格

- 輸入一行，只有大寫 `O` 和 `X`，長度不限，**也可能是空的**（還沒有任何紀錄）。
- 印出最長的連續 `O` 有幾個。沒有任何 `O` 時印 `0`。

| 輸入 | 應該印出 | 說明 |
|---|---|---|
| `XOOOX` | 3 | 中間那段 OOO |
| `XXOOX` | 2 | 那段 OO |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式，照著上面的例子，在紙上一圈一圈追 `streak` 和 `best` 的變化。
2. 在表格的「輸入」欄打一組打卡紀錄，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，說說看是哪幾行讓它出錯。

> 想不出來時，想想這些位置：最前面、最後面、什麼都沒有、全部都一樣。這就是單元 08 說的「邊界」：AI 寫的迴圈最常錯在這裡，而一般的輸入抓不到。
