# 打工薪資（黑箱題）

餐廳的薪資程式輸入上班時間、下班時間（都是整點）和時薪，算出實際工時和薪資。薪資不只是「時數 × 時薪」。

輸入：

```
9
18
200
```

印出：

```
工時 8 小時，薪資 1600 元
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 在店裡待幾小時以上，會**扣掉休息時間**？扣多少？**剛好那個時數**會扣嗎？
   - 工時超過幾小時算**加班**？加班時薪是幾倍？只有超過的部分，還是全部？
   - 加班費有小數時怎麼處理？
   - **下班時間比上班時間小**（例如 22 點上班、2 點下班），怎麼算？上下班時間一樣呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
