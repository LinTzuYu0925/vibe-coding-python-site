# 設定檔的音量（抓錯題）

一個小遊戲把使用者的設定存在 `settings.json`。程式讀這個檔案，印出音量。

## 規格

- `settings.json` 是一個 JSON 物件，例如 `{"name": "小明", "volume": 30}`。
- `"volume"` 是 0 到 100 的整數。**有寫就照寫的用**。
- 沒有 `"volume"` 這一項時，用預設值 50。
- 印出一行：`音量 N`。

| settings.json 的內容 | 應該印出 |
|---|---|
| `{"volume": 30}` | 音量 30 |
| `{"name": "小明"}` | 音量 50 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的內容：

1. 讀程式。`json.load(f)` 把檔案裡的 JSON 變成 dict（單元 12）；`.get("volume", 0)` 是「有這一項就拿出來，沒有就給 0」（單元 07）。
2. 在表格的第一欄打 `settings.json` 的內容（一行就好），旁邊會自動出現這個程式印出什麼。網頁會先把你打的內容存成 `settings.json`，再執行程式。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`.get` 的第二個值應該填什麼，就不用後面那個 `if`？

> 想想看：程式用「是不是 0」判斷「有沒有寫音量」。這兩件事一定一樣嗎？
