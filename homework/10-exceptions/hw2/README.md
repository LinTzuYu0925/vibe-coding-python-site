# 聚餐分攤（抓錯題）

聚餐後要分攤帳單。輸入總金額和人數，程式算出每人要付多少，不夠整除的零頭另外算。

## 規格

- 輸入一行：`金額 人數`，用空格隔開。
- 兩個都是整數時：
  - 人數是 0 或負數，印 `人數要大於 0`。
  - 金額是負數，印 `金額不能是負數`。人數和金額都不對時，先看人數。
  - 其他情況印 `每人 A 元，剩 B 元`（`A` 是整除的商，`B` 是餘數）。
- 不是剛好兩個整數（有文字、有小數、少打、多打），印 `請輸入兩個整數`。

| 輸入 | 應該印出 |
|---|---|
| `1000 4` | 每人 250 元，剩 0 元 |
| `abc 4` | 請輸入兩個整數 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`input().split()` 把一行從空格切開，這個寫法課程沒有教；切出來不是剛好兩段時，`total, people = ...` 這行會出現 `ValueError`。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`except` 那一行應該改成什麼？還要多加哪些檢查？
