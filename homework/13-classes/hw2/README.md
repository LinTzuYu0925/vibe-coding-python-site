# 帳戶領錢（抓錯題）

AI 寫了一個 `Account`（帳戶）類別。帳戶一開始有 100 元，輸入要領的金額，印出結果和餘額。

## 規格

- 輸入一行：要領的金額（整數）。
- 金額是 0 或負數：印 `金額無效，餘額 100 元`。
- 金額比餘額大：印 `餘額不足，餘額 100 元`。
- 其他情況：領出這筆錢，印 `領出 N 元，餘額 M 元`，`M` 是**領完以後**的餘額。

| 輸入 | 應該印出 |
|---|---|
| `150` | 餘額不足，餘額 100 元 |
| `0` | 金額無效，餘額 100 元 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`withdraw` 是帳戶的方法，`self.balance` 是帳戶的屬性（單元 13）。
2. 在表格的「領出金額」欄打一個數字，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，指出是哪一行、少了什麼。

> 想想看：方法裡的 `balance` 和 `self.balance` 是同一個東西嗎？
