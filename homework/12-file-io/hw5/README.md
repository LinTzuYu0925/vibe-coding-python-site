# 記帳月報（黑箱題）

記帳 App 匯出了 `expenses.csv`。月報程式讀這個檔案，算出每個類別花了多少錢。資料是手打的，有些行不太對，程式自有一套處理方法。

`expenses.csv` 的內容：

```
日期,類別,金額
11/01,餐飲,120
11/02,交通,30
11/02,餐飲,85
```

印出：

```
餐飲 205
交通 30
合計 235
```

## 你的任務

1. **試黑箱**：在「試試黑箱」打 `expenses.csv` 的內容，找出下面問題的答案：
   - 類別是照什麼**順序**排的？兩個類別金額**一樣**時呢？
   - **負的金額**是什麼意思？會怎麼算？
   - 金額不是整數（`85.5`、`一百`、空的）的那一行怎麼辦？會告訴你嗎？什麼時候才告訴你？
   - **類別是空的**呢？類別前後有空格呢？
   - 一行的欄位**太多或太少**呢？空白行呢？
   - 只有標題、或沒有任何能算的資料時，印什麼？
2. **寫規格**：把規則寫清楚，每條附一個「`expenses.csv` 內容 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
