# 修好自我介紹卡（傳統題）

`starter.py` 應該印出下面這張自我介紹卡，可是裡面藏了 **3 個錯誤**，一執行就出現錯誤訊息。

```
===== 自我介紹 =====
姓名：王小明
課程：Vibe Coding with Python
今天完成：安裝 Python 3.12
下一步：學變數
```

## 你的任務

1. 在 VS Code 開啟 `starter.py`，在終端機輸入 `python starter.py` 執行。（也可以直接用下方的程式框，按「檢查範例」。）
2. 讀錯誤訊息的**最後一行**和它指出的**行號**，找到那一行，修好它。
3. 再執行一次。Python 一次只報**一個**錯誤：修好一個，下一個才會出現。
4. 3 個都修好，印出的內容和上面一模一樣，就完成了。

看不懂錯誤訊息時，把**整段**錯誤訊息貼給 Codex 或 Claude，請它「解釋這個錯誤，並告訴我是哪一行」。先讓它解釋，再自己動手改。

> 提示：其中一個錯誤，是用中文輸入法時最常發生的。仔細比較每一行的括號和引號。
