# 不會當掉的計算機（黑箱題）

這個計算機一行算一題，格式是 `數字 運算子 數字`。使用者會打錯，但它**不會當掉**，而且會說清楚錯在哪裡。

輸入：

```
7 - 2
8 / 0
結束
```

印出：

```
5.00
不能除以 0
成功 1 筆，失敗 1 筆
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 答案固定印幾位小數？
   - 總共有**幾種**錯誤訊息？（試試少打一段、多打一段、打文字、除以 0、用 `%`。）`5 / 0.0` 呢？
   - 一行同時有**兩種**錯時，印哪一個？試出檢查的順序。
   - 空白行算錯嗎？多打空格呢？`2+3` 沒有空格呢？
   - 最後一行的成功、失敗，怎麼算？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
