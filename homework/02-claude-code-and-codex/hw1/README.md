# 月報摘要（黑箱題）

記帳小工具要加一個「月報」功能：輸入一個月份和很多筆記帳，它列出那個月每個類別花了多少錢。

下方的「試試黑箱」就是已經做好的月報程式。輸入格式如下（下方「範例」也可以直接複製來改）：

```
2026-10
2026-10-01,餐飲,65
2026-10-02,交通,30
2026-10-03,餐飲,120
結束
```

上面只示範了最普通的情況。**真正的規則要你自己試出來**，下面每個問題都要試：

- 類別的排列順序是照什麼排的？兩個類別金額一樣時呢？
- 那個月一筆都沒有，會印什麼？
- 有一行寫錯（少一欄、多一欄、空白行、沒寫類別、金額是 0、負數、小數或不是數字），會怎樣？
- 寫錯的那一行如果是**別的月份**，也算嗎？
- 日期的格式不對（例如 `2026/10/05`），處理方式和金額寫錯一樣嗎？
- 逗號前後多打空格，或金額前面多打 0（例如 `065`），這一行還算數嗎？
- 「結束」後面還有資料，它會讀嗎？忘了打「結束」，又會怎樣？

## 你的任務

1. **試黑箱**：把上面每個問題的答案記在筆記裡（例如「金額一樣時……」）。
2. **在 Codex（或 Claude Code）裡實作**：在你的專案資料夾開一個新對話，用 Plan mode 寫需求：功能、輸入輸出格式（可直接貼「給 AI 的格式說明」）、你找到的規則、驗收方式。先審計畫，再讓它動手。
3. **自己執行**：在終端機執行 `python monthly.py`，用你試黑箱時的同一組輸入，比對兩邊的輸出。
4. **檢查**：把 `monthly.py` 的內容貼到下方的程式框，按「檢查範例」。

範例全部通過只是起點。回到「試試黑箱」，把你試過的每一組特殊輸入，按「也跑我的程式，比對」：每一組都要一模一樣。
