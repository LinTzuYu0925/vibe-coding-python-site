# 成績 CSV 摘要（傳統題）

助教把成績存成 `grades.csv`，可是有些格子是空的、有些打錯。寫一個程式讀這個檔案，算出平均和最高分，並告訴助教略過了幾筆。

## 規格

- 讀 `grades.csv`。第一行一定是標題 `姓名,分數`，之後每行一位學生。
- **分數**去掉前後空格後，必須是整數才算；空的、不是整數（例如 `八十`、`85.5`）、或整欄沒有，這一筆就**略過**。姓名也要去掉前後空格。
- 完全空白的行不算一筆，也不算略過。
- 至少有一筆有效資料時，印出三行：`平均 X 分`、`最高 姓名 分數 分`、`略過 N 筆`（見下面的例子）。平均保留**一位**小數。最高分有好幾個人同分時，印**最先出現**的那位。
- 沒有任何有效資料時，印兩行：`沒有有效資料`、`略過 N 筆`。

例如 `grades.csv` 的內容是：

```
姓名,分數
小明,70
小華,95
小美,
小強,85
```

印出：

```
平均 83.3 分
最高 小華 95 分
略過 1 筆
```

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

會用到單元 12 的 `csv.DictReader`（記得：每一格讀進來都是**字串**）、單元 10 的 `try`／`except ValueError`。

> 小提醒：一行如果連逗號都沒有（例如只有 `小明`），`DictReader` 給的分數會是 `None`，不是空字串。先想好怎麼處理。
