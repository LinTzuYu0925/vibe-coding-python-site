# 電費帳單（黑箱題）

電力公司的計費程式輸入用電度數和月份（各一行），算出電費。

輸入：

```
100
1
```

印出：

```
電費 250
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 用 **0 度**時要繳多少？這筆錢每個月都有嗎？
   - 每度多少錢？用得越多，後面的度數會變貴嗎？**分界在幾度**？
   - 跨過分界時，是全部度數都變貴，還是只有超過的部分？
   - 有些**月份**比較貴嗎？是哪幾個月？貴多少？基本的錢也一起變貴嗎？
   - 算出來有小數時，怎麼處理？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
