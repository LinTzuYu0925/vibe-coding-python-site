# 停車場（黑箱題）

停車場入口的機器只認車牌：輸入一行車牌，機器自己判斷這台車是要進來還是要出去，還會顯示剩幾個車位。輸入 `結束` 時，印出場內還有幾台車。

輸入：

```
ABC-123
XYZ-789
ABC-123
結束
```

印出：

```
ABC-123 進場，剩 2 位
XYZ-789 進場，剩 1 位
ABC-123 出場，剩 2 位
場內 1 台
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的車牌，找出下面問題的答案：
   - 停滿了再來一台車會怎樣？那台車之後再來一次呢？
   - 機器怎麼知道車子是要**出場**？
   - **小寫**的車牌（`abc-123`）和大寫的算同一台嗎？前後有空格呢？
   - **空白行**會怎樣？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。請 AI 用類別 `ParkingLot`，車子的清單和剩幾位都是它的屬性。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
