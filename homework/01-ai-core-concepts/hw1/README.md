# 記帳自動分類（黑箱題）

記帳 App 裡有一位「分類小幫手」：你輸入一個品項名稱，它回答這筆花費屬於哪一類。
它認得下面這些關鍵字：

| 分類 | 關鍵字 |
|---|---|
| 餐飲 | 早餐、午餐、晚餐、咖啡、飲料 |
| 交通 | 捷運、公車、計程車、高鐵 |
| 娛樂 | 電影、唱歌、遊戲 |

可是，**它的完整規則沒有寫出來**。例如：

- 「星巴克咖啡」不完全等於「咖啡」，它會怎麼分？
- 「高鐵咖啡」同時有交通和餐飲的關鍵字，它選哪一類？
- 什麼都沒輸入，它會回答什麼？

這種「看不到裡面、只能從外面試」的程式，叫做**黑箱**。

## 你的任務

1. **試黑箱**：在下方「試試黑箱」輸入各種品項名稱，觀察它的回答。至少試出 3 條上面表格沒寫的規則。
2. **寫 Prompt（提示詞）**：用單元 01 的四個檢查點（① 目標 ② 輸入與輸出 ③ 限制 ④ 驗收），把你找到的規則寫清楚。記得把「給 AI 的格式說明」也貼進去。
3. **交給 AI**：把 Prompt 貼到免費的 ChatGPT 或 Claude 網頁版，請它寫程式。
4. **檢查**：把 AI 給你的程式**整段**貼到下方的程式框，按「檢查範例」。

範例全部通過，不代表規則都對了。回到「試試黑箱」，輸入你試出來的特殊名稱，按「也跑我的程式，比對」：每一個都要一模一樣。不一樣的地方，就補進 Prompt，請 AI 修改。

> 為什麼要這樣做？AI 只知道你告訴它的事情。你沒發現的規則，它也不會知道。
