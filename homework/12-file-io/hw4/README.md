# 待辦清單（黑箱題）

待辦清單存在 `todo.txt`，一行一項。程式讀這個檔案，列出還沒做完的事。

`todo.txt` 的內容：

```
買牛奶
x 繳電話費
寫作業
```

印出：

```
未完成 2 項
1. 買牛奶
2. 寫作業
已完成 1 項
```

## 你的任務

1. **試黑箱**：在「試試黑箱」打 `todo.txt` 的內容，找出下面問題的答案：
   - 怎樣算「已完成」？開頭的 x 一定要小寫嗎？後面一定要有空格嗎（試試 `xbox` 這種項目）？
   - **空白行**算一項嗎？
   - 用 `#` 開頭的行呢？
   - 項目前後的空格會留著嗎？
   - **全部做完**時印什麼？**空檔案**呢？
2. **寫規格**：把規則寫清楚，每條附一個「`todo.txt` 內容 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

在自己電腦上執行時，在 `.py` 旁邊建一個 `todo.txt`，貼上上面的內容。
