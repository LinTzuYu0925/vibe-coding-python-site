# 圓的面積（傳統題）

輸入半徑，算出圓的面積和周長。

## 規格

- 輸入一行：半徑（0 以上的整數）。
- 印出兩行：`面積 X`、`周長 Y`，都保留兩位小數。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `5` | 面積 78.54／周長 31.42 |
| `1` | 面積 3.14／周長 6.28 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。請 `import math`，用 `math.pi`，不要自己打 3.14。

不用 AI 也能完成。面積是 π × 半徑 × 半徑，周長是 2 × π × 半徑。
