# 停車場計費（黑箱題）

停車場的收費機壞了，只剩下它的程式還能跑。你要依照它的行為，寫出一個一模一樣的新版本。

輸入：每行一台車的停車**分鐘數**，最後一行是 `結束`。
輸出：每台車一行停車費，最後一行是全部車的 `總收入`。

```
10
45
90
結束
```

這組輸入會印出 `0`、`40`、`60`、`總收入 100`。光看這幾個數字，還猜不出完整的收費規則。

## 你的任務

1. **試黑箱**：用「試試黑箱」把收費規則完整找出來。提示：
   - 幾分鐘以內免費？剛好在那個分鐘數呢？多 1 分鐘呢？
   - 費用是怎麼一段一段跳的？31 分鐘和 30 分鐘一樣嗎？
   - 停一整天，費用會一直加上去嗎？
   - 輸入負數、或不是數字，會怎樣？會算進總收入嗎？
2. **寫規格**：把規則寫成條列，每條附一個「輸入 → 輸出」的例子；分界的地方（剛好、多 1）一定要有例子。
3. **實作**：把規格交給 AI，或自己寫。需要用到 `while`、`if／elif／else`，以及「不滿一段也算一段」的計算。
4. **檢查**：把程式貼到下方程式框，按「檢查範例」；再把你規格裡的每個例子輸入「試試黑箱」，按「也跑我的程式，比對」。
