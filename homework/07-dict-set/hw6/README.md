# 單字統計（黑箱題）

文字分析工具讀入一句英文，統計單字數量，並找出出現最多次的單字。

輸入：

```
the cat and the dog
```

印出：

```
單字 5 個，不同 4 個
最多 the 2 次
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - `The` 和 `the` 算同一個單字嗎？印出來是哪一種寫法？
   - 單字後面黏著標點（`dog,`、`cat!`），會怎樣？哪些標點會被拿掉？
   - 只有標點、沒有單字，算幾個？什麼都沒輸入呢？
   - 兩個單字**同樣多次**時，印哪一個？
   - `it's`、`a,b` 這種**中間**有標點的呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
