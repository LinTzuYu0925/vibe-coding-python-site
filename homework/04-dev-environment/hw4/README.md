# 名牌產生器（黑箱題）

活動現場輸入名字，程式印出一張用星號框起來的名牌。

輸入：

```
Python
```

印出：

```
**********
* PYTHON *
**********
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 星號那一行的**長度**和名字有什麼關係？
   - 輸入小寫英文，會變成什麼？
   - 名字前後多打空格，會怎樣？什麼都沒打呢？
   - 名字**很長**時會怎樣？從幾個字開始不一樣？**剛好那個長度**呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI。在 VS Code 裡請 AI 助手實作，存檔後在終端機執行。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
