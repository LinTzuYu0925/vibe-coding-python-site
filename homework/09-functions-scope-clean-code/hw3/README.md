# 購物車結帳（傳統題）

網路商店要計算購物車的應付金額：先看能不能打折，再看要不要收運費。把這兩條規則各寫成一個函式。

## 規格

寫兩個函式：

- `discount(subtotal)`：參數是小計（0 以上的整數），**回傳**折扣後的金額。
  - 小計滿 1000（剛好 1000 也算）打 9 折，小數無條件捨去；不滿 1000 不打折。
- `shipping(total)`：參數是折扣後的金額（0 以上的整數），**回傳**運費。
  - 滿 500（剛好 500 也算）免運，也就是 0 元；不滿 500 收 60 元。
  - **金額是 0（購物車是空的）時不收運費**，回傳 0。

兩個函式都**回傳整數**，函式裡不要 `print`。只寫函式就好，**不要寫 `input()`，也不要寫主程式**。

商店的主程式會這樣用你的函式：`total = discount(subtotal)`、`fee = shipping(total)`、應付 `total + fee`。

## 網頁怎麼檢查

網頁會在你的程式後面接上一段測試程式，用同一個金額分別呼叫兩個函式：

```python
discount(1111)    # 應該回傳 999
shipping(1111)    # 應該回傳 0
discount(300)     # 應該回傳 300
shipping(300)     # 應該回傳 60
```

測試程式把回傳值印出來，再和「應該印出」比對。所以函式名稱要一模一樣，`999.9` 和 `999` 也不一樣。完整的測試程式在下方「看看測試程式」。
