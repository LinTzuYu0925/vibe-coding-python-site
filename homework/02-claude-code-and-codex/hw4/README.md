# 旅行分帳（黑箱題）

朋友一起旅行，每個人先墊了一些錢。分帳程式算出每個人**該收回**（正）或**該再付**（負）多少，讓大家付得一樣多。

輸入：

```
阿光,600
阿雅,0
結束
```

印出：

```
阿光 +300.0
阿雅 -300.0
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 同一個人有**兩筆**時怎麼算？
   - 輸出的**順序**是照什麼排的？差額一樣時呢？
   - 差額是 0 時怎麼印？除不盡時保留幾位？
   - 金額是 **0** 的人算有參加嗎？金額是負數、不是整數、少一欄呢？
   - 壞資料會讓最後多印一行嗎？一筆資料都沒有呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI。在 Codex 或 Claude Code 裡用 Plan mode 實作。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
