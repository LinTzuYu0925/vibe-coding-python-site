# 時鐘往後撥（傳統題）

現在幾點幾分？再過一段時間以後，時鐘上顯示幾點幾分，又過了幾天？（24 小時制）

## 規格

- 輸入三行：時（0～23）、分（0～59）、要往後撥的分鐘數（0 以上）。
- 印出一行：`H 時 M 分，過了 D 天`。`D` 是跨過午夜幾次。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `10`、`30`、`45` | 11 時 15 分，過了 0 天 |
| `23`、`30`、`45` | 0 時 15 分，過了 1 天 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。**不需要** `if`，只用 `+`、`*`、`//`、`%`。
