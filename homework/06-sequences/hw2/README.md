# 最近幾天的步數（抓錯題）

運動 App 要顯示「最近 n 天一共走了幾千步」。

## 規格

- 輸入一行整數，用空格隔開：
  - **第一個**數字是 n（0 以上的整數）：要看最近幾天。
  - **後面**是每天的步數（千步），至少 1 天，**最舊的在前面、最新的在最後**。
- 印出最近 n 天的步數合計。n 比天數還多時，就是全部天數的合計。

| 輸入 | 應該印出 | 說明 |
|---|---|---|
| `3 5 8 2 9 4` | 15 | 最近 3 天是 2、9、4 |
| `5 7 1` | 8 | 只有 2 天，全部加起來 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`numbers[1:]` 是「從索引 1 到最後」；`days[-n:]` 是「最後 n 個」（單元 06 的負索引和切片）。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，在終端機輸入 `python`，自己試試 `[5, 8, 2][-0:]` 是什麼。

> 想想邊界：規格說 n 是「0 以上」。n 最小可以是多少？
