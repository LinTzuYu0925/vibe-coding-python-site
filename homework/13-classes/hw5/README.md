# 會員點數卡（黑箱題）

咖啡店的會員卡：每次消費會得到點數，點數可以兌換飲料，消費夠多還會升級。輸入一行一筆消費金額（或是指令），輸入 `結束` 時印出會員卡的狀態。

輸入：

```
450
1280
結束
```

印出：

```
消費 450 元，得 4 點，共 4 點
消費 1280 元，得 12 點，共 16 點
普通卡，累計消費 1730 元，點數 16 點
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 點數怎麼算？**不滿**的部分呢？
   - 累計消費**到多少**會升級？**剛好**那個金額呢？升級的那一筆，點數用哪個等級算？
   - 升級以後，點數有什麼不一樣？
   - 輸入 `兌換` 會怎樣？點數**不夠**時呢？
   - 金額是 0、負數、小數或文字時呢？會影響累計嗎？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。請 AI 用類別 `MemberCard`，等級、累計消費、點數都是它的屬性，消費和兌換是它的方法。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
