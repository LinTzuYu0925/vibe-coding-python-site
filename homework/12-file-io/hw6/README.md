# JSON 成績排名（黑箱題）

另一個系統把成績匯出成 `scores.json`：每位學生對應一串成績。排名程式讀這個檔案，依平均分數排出名次。

`scores.json` 的內容：

```
{"小明": [80, 90], "小華": [95, 88, 92]}
```

印出：

```
1. 小華 91.7
2. 小明 85.0
```

## 你的任務

1. **試黑箱**：在「試試黑箱」打 `scores.json` 的內容，找出下面問題的答案：
   - 平均**一樣**的兩個人，名次怎麼排？下一位是第幾名？
   - 成績串列是**空的** `[]` 時呢？這個人排在哪裡？
   - 成績裡混了**文字**（例如 `"90"`）或 `null` 呢？
   - 成績**不是串列**（例如直接寫 `85`）呢？
   - 檔案**不是正確的 JSON**、是空的、或最外層不是 `{ }` 時，印什麼？一個學生都沒有呢？
2. **寫規格**：把規則寫清楚，每條附一個「`scores.json` 內容 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 提示：JSON 的字串一定要用**雙引號**，`{'小明': [80]}` 不是正確的 JSON。
