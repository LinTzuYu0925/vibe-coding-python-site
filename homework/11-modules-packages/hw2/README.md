# 遊覽車台數（抓錯題）

學校辦校外教學，一台遊覽車坐 40 人。輸入人數，算出要租幾台車，所有人都要坐得下，車不能多租。

## 規格

- 輸入一行：人數，0 以上的整數。
- 印出 `需要 N 台車，最後一台空 M 個位子`。
- 人數是 0 時不用租車：`N` 和 `M` 都是 0。

| 輸入 | 應該印出 |
|---|---|
| `85` | 需要 3 台車，最後一台空 35 個位子 |
| `1` | 需要 1 台車，最後一台空 39 個位子 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`math.floor` 是無條件捨去（單元 11 教過）。
2. 在表格的「輸入」欄打一個人數，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：單元 11 的 `math` 裡，有哪個現成的函式可以取代 `math.floor(...) + 1`？

> 想想看：「捨去再加 1」看起來等於「無條件進位」。什麼時候這兩個不一樣？
