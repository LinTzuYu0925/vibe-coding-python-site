# 會員結帳（傳統題）

飲料店有價目表和會員等級，輸入品項、數量和會員等級，算出應付金額和點數。

| 品項 | 單價 |
|---|---|
| 紅茶 | 30 |
| 奶茶 | 50 |
| 咖啡 | 60 |
| 蛋糕 | 90 |

| 等級 | 折數 | 每 100 元的點數 |
|---|---|---|
| 金卡 | 80 | 3 |
| 銀卡 | 90 | 2 |

## 規格

- 輸入三行：品項、數量（0 以上的整數）、會員等級。
- 算法：
  - 應付 = 單價 × 數量 × 折數 ÷ 100，小數無條件捨去（用 `//`）。
  - 點數 = 應付裡有幾個完整的 100 元 × 每 100 元的點數。
- 不在價目表的品項，單價當成 0。
- 不是金卡、銀卡的等級（包含空白），折數當成 100，每 100 元的點數當成 1。
- 印出兩行：`單價 P，折數 R`、`應付 T，點數 Q`。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `紅茶`、`2`、`金卡` | 單價 30，折數 80／應付 48，點數 0 |
| `蛋糕`、`3`、`銀卡` | 單價 90，折數 90／應付 243，點數 4 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。這題**不用** `if`：把會員資料寫成**巢狀 dict**，用 `.get()` 處理查不到的情況。
