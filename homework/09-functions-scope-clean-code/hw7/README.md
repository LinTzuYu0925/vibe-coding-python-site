# 學號檢查器（黑箱題）

學校的系統會檢查學號有沒有打錯。學號的規則沒有公開，但錯誤訊息會告訴你是哪裡不對。下面的例子是一個有效的學號。

輸入：

```
S123455
```

印出：

```
有效
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 學號要**幾個字**？長度不對時印什麼？
   - 第一個字可以是哪些字母？（把字母一個一個換掉試試。）小寫可以嗎？
   - 後面可以有數字以外的字嗎？
   - **最後一碼**和前面的數字有什麼關係？（只改最後一碼，看哪一個數字才有效；再改前面的一個數字，看它怎麼跟著變。）
   - 同時有兩種錯時，印哪一個？試出檢查的順序。
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
