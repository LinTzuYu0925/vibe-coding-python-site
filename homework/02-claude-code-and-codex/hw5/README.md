# 最新的記帳日期（抓錯題）

使用者手動輸入日期，格式是 `年-月-日`。程式要找出最新的一天。

## 規格

- 輸入一行：至少 1 個日期，用空格隔開。**月、日可能沒有補 0**，例如 `2026-9-5`。
- 印出 `最新的日期是 X`，`X` 照輸入時的寫法印。

| 輸入 | 應該印出 |
|---|---|
| `2026-10-05 2026-11-01` | 最新的日期是 2026-11-01 |
| `2025-12-31 2026-01-01` | 最新的日期是 2026-01-01 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面的例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`max()` 會找出最大的那一個。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：文字比大小和數字比大小，哪裡不一樣？怎麼讓它照真正的日期比？
