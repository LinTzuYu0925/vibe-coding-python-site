# 每隔幾號點名（抓錯題）

老師從某個座號開始，每隔幾號點一個人，一直點到終點。**終點如果剛好點到，也要算進去。**

## 規格

- 輸入一行：`起點 終點 間隔`，三個整數，起點不大於終點，間隔至少是 1。
- 印出 `座號 [...]`，列出所有點到的座號。

| 輸入 | 應該印出 |
|---|---|
| `1 10 2` | 座號 [1, 3, 5, 7, 9] |
| `2 9 3` | 座號 [2, 5, 8] |

## 你的任務

AI 依照這份規格寫了下方的程式。上面的例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。第一行把三個數字分別放進 `a`、`b`、`step`，這個寫法課程沒有教，知道它的結果就好。`range(開始, 結束, 間隔)` 單元 06 教過。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`range` 的第二個數字應該怎麼改？
