# 學期成績（黑箱題）

學校的成績系統讀入一位學生的**國文、英文、數學**三科分數（每行一個整數），印出：

```
學期成績 71.6
及格 True
```

可是學期成績**不是三科的平均**（80、72、65 的平均是 72.3），及格的規則也沒寫。

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入三個分數，找出下面 3 件事：
   - 三科各占學期成績的**幾成**？
   - 學期成績**剛好 60**，算不算及格？
   - 學期成績 60 以上，就**一定**及格嗎？如果還有別的條件，分界在幾分？剛好那個分數算過嗎？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 提示：怎麼設計輸入，才能**一次只看一科**的影響？試試只有一科有分數、其他兩科是 0。
