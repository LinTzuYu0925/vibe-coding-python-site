# 共同好友（黑箱題）

社群網站有一個「共同好友」功能：輸入我的好友和對方的好友（各一行，名字用空格隔開），它列出兩邊的比較結果。

輸入：

```
Tom Uma Vic
Vic Wes Uma
```

印出：

```
共同好友 ['Uma', 'Vic']
只有我認識 ['Tom']
只有對方認識 ['Wes']
總共 4 人
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的名單，找出下面 5 個問題的答案：
   - 同一行裡，同一個名字打**兩次**，會算兩個人嗎？
   - 名單印出來的**順序**是照什麼排的？和輸入的順序有關嗎？
   - `amy` 和 `Amy` 算同一個人嗎？大寫和小寫哪個排前面？
   - 其中一行**什麼都沒打**（直接按 Enter），會印什麼？
   - 兩邊都沒有共同好友時，第一行印什麼？
2. **寫規格**：用單元 07 學的 set（集合）把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 想想看：set 沒有順序（單元 07 教過）。要讓每次印出來都一樣，要多做哪一步？
