# 圖書館逾期罰金（黑箱題）

圖書館的系統輸入借書日期和還書日期（各一行），算出要不要繳罰金。

輸入：

```
2026-03-01
2026-03-20
```

印出：

```
逾期 5 天，罰金 25 元
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的日期，找出下面 6 個問題的答案：
   - 可以借**幾天**不算逾期？剛好最後一天還呢？多一天呢？
   - 逾期一天罰多少？
   - 罰金會一直加上去，還是有**上限**？上限是多少？
   - **跨月、跨年**算得對嗎？二月有 28 天還是 29 天，會影響答案嗎？（試試 2028 年和 2027 年的 2 月。）
   - 還書日期**早於**借書日期，會怎樣？
   - 不存在的日期（例如 2 月 30 日、13 月）或不是日期的文字，會怎樣？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。讀程式時確認：它有用 `datetime`（單元 11），還是自己算每個月有幾天？
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 想想看：單元 11 說「先問標準函式庫有沒有現成的」。閏年的規則，你想自己寫嗎？
