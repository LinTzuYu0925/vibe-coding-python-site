# 成績 Dataset（傳統題）

把學生的姓名和分數收進一個 `Dataset` 類別，讓它自己算人數、平均、最高分。同一個人輸入兩次時，用**新的**分數（例如補考）。

## 規格

- 寫一個類別 `Dataset`，至少有這些方法：
  - `add(self, name, score)`：加入一位學生；同名的人已經在裡面，就**改成新的分數**，不多算一人。
  - `count(self)`：回傳人數。
  - `average(self)`：回傳平均。
  - `best(self)`：回傳最高分的姓名和分數。同分時，回傳**最先加入**的那位（改過分數的人，還是算他第一次加入的位置）。
- 主程式：一次讀兩行，第一行姓名、第二行分數（整數）；姓名那行是 `結束` 就停。姓名去掉前後空格。
- 至少有一位學生時，印三行：

```
人數 3
平均 81.7
最高 小華 92
```

  平均保留**一位**小數。一位都沒有時只印 `沒有資料`。

例如輸入（每行一個）：小明、70、小華、92、小美、83、結束，印出上面三行。

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

會用到單元 13 的 `class`、`__init__`、`self`、方法，以及單元 07 的 dict（用姓名當 key，同名自然就會被蓋掉）。網頁只看印出的內容，但這題要練的是把資料和動作包進類別：主程式只負責讀輸入、呼叫方法、印結果。
