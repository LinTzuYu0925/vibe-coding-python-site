# 記帳小工具：各階段的備案檔案（講師用）

學員的 AI 額度用完、或某一步沒做出來時，把對應資料夾**裡面的所有檔案**複製到學員自己的 `my-expenses` 資料夾（覆蓋同名檔案），就能從下一個練習接著做。

| 資料夾 | 完成哪一頁之後 | 內容 |
|---|---|---|
| `step0-start` | 電腦基本功：建好專案資料夾 | `expenses.csv`（5 筆，總金額 620） |
| `step1-list` | 寫需求、看它工作、自己算自己跑 | v1：列出每一筆＋總金額 |
| `step2-add` | 新增一筆、逐條測試 | v2：選單 1 列出／2 新增／0 離開，會檢查輸入 |
| `step3-rules` | 規則檔 AGENTS.md | v2＋`AGENTS.md` |
| `step4-pointer` | 指路牌 | v3（加上 3 分類小計）＋`AGENTS.md`（含「需要時再讀」）＋`docs/categories.md` |
| `step5-notes` | 經營 Context | ＋`NOTES.md` |
| `step6-skill` | Agent Skill | ＋`.agents/skills/monthly-report/SKILL.md` |

學員要貼給 Codex 的文字全部整理在 `prompts.md`（由投影片的「貼給 Codex」框自動整理，改投影片後請重新產生）。

## 注意

- `.agents` 開頭是點的資料夾：檔案總管看得到，但複製時請確認有一起複製。
- `expenses.csv` 只用記事本看，**不要用 Excel 存檔**：Excel 可能把中文改成別的編碼，程式就讀不了。
- 備案檔案不含 `.git`。學員若需要存檔點，請 Agent 在自己的資料夾執行 git init 與 commit。

## 已驗證的結果（Python 3.11，2026-10-28）

- v1：列出 5 筆，總金額 620。
- v2：項目空白、金額 -50、0、abc、`²`、日期 2026-10-32 都只顯示提示，不新增、不當掉；新增「2026-10-06 晚餐 150」後總金額 770。
- v3：分類小計為 餐飲 270、交通 30、娛樂 320；新增「文具 40」後多出「其他：40」。
- 月報（step6）是 Agent 依 SKILL.md 產生的，每次文字可能不同；以原始 5 筆資料核對：筆數 5、總金額 620、最大一筆 2026-10-05 電影 320。
