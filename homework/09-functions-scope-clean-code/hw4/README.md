# 成績等第（傳統題）

寫一個函式，把分數換成等第。

| 分數 | 等第 |
|---|---|
| 90 以上 | A |
| 80～89 | B |
| 70～79 | C |
| 60～69 | D |
| 60 以下 | F |

## 規格

寫一個函式 `grade(score)`：

- 參數 `score` 是 0～100 的整數。
- **回傳**等第，一個大寫字母，例如 `"A"`。不是 `"等第 A"`，也不要在函式裡 `print`。

只寫函式就好，**不要寫 `input()`，也不要寫主程式**。

## 網頁怎麼檢查

網頁會在你的程式後面接上一段測試程式，直接呼叫你的函式：

```python
grade(95)    # 應該回傳 'A'
grade(72)    # 應該回傳 'C'
```

測試程式把回傳值印出來，再和「應該印出」比對。函式裡用 `print` 印出答案、沒有 `return`，會被抓到。完整的測試程式在下方「看看測試程式」。

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

不用 AI 也能完成。剛好在分界上的分數（例如 80）要特別注意。
