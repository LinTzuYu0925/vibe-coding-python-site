# 叫號機（黑箱題）

銀行的叫號機：客人按「取號」拿號碼牌，櫃台按「叫號」叫下一位。輸入一行一個指令，輸入 `結束` 時印出還有幾人在等。

輸入：

```
取號
取號
叫號
結束
```

印出：

```
你的號碼 1，前面有 0 人
你的號碼 2，前面有 1 人
請 1 號
還有 1 人在等
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的指令，找出下面問題的答案：
   - 沒有人在等時**叫號**會怎樣？
   - 等候的人**最多**幾個？滿了再取號會怎樣？被拒絕的那次，號碼有沒有被用掉？
   - 除了「取號」「叫號」，還有一個指令 `重叫`：它做什麼？還沒叫過任何號時呢？
   - 打錯指令、前後有空格、空白行呢？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。請 AI 用類別 `TicketMachine`，等候的號碼、下一個號碼、上一個叫的號碼都是它的屬性。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
