# 有沒有人不及格（抓錯題）

老師想知道全班有沒有人不及格（低於 60 分）。

## 規格

- 輸入一行：至少 1 個整數，用空格隔開。
- 只要有一個人低於 60，印 `有人不及格`；全部都 60 以上，印 `全部及格`。

| 輸入 | 應該印出 |
|---|---|
| `50 70` | 有人不及格 |
| `70 80` | 全部及格 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面的例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`[int(x) for x in input().split()]` 把一行數字變成 list，這個寫法課程沒有教。`return` 會**立刻結束函式**（單元 09）。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`return False` 應該放在哪裡？縮排要怎麼改？
