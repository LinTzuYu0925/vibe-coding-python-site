# 感測器資料清理（黑箱題）

溫度感測器每隔一段時間傳回一筆資料，可是線路不穩，有些資料是壞的。清理程式要算出有效資料的平均，而且**不管收到什麼都不能當掉**。

輸入：

```
21.5
abc
23.5
結束
```

印出：

```
有效 2 筆，壞資料 1 筆
平均 22.5
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入各種資料，找出下面 6 個問題的答案：
   - 溫度**範圍**是多少？超出範圍算壞資料嗎？（這個感測器的上下限是整數，試試 `-41`、`86`，再往裡面找。）
   - **剛好在上限或下限**上，算有效嗎？多 0.1 呢？
   - **空白行**算壞資料，還是直接跳過？數字**前後有空白**呢？
   - `30度`、`12,5`、`二十` 算什麼？
   - `nan`、`inf`、`1e1` 這幾個字，Python 的 `float()` 都轉得過去（`1e1` 是 10）。黑箱把它們當成什麼？
   - **全部都是壞資料**，或一筆都沒有時，第二行印什麼？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。檢查 AI 的 `except`：有沒有接得太寬（單元 10）？
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 想想看：全部壞掉時，平均要除以 0。程式是先檢查，還是等它出錯再接住？
