# 最高分與第一位交卷（抓錯題）

老師照交卷的順序輸入全班分數，想知道最高分，還有第一位交卷的學生考幾分。

## 規格

- 輸入一行：至少 1 個整數，用空格隔開，順序就是**交卷的順序**。
- 印出 `最高分 A，第一位交卷 B`。

| 輸入 | 應該印出 |
|---|---|
| `50 70 90` | 最高分 90，第一位交卷 50 |
| `85` | 最高分 85，第一位交卷 85 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面兩個例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。`[int(x) for x in input().split()]` 把一行數字變成 list，這個寫法課程沒有教，知道它的結果就好。`.sort()` 是單元 06 教過的排序。
2. 在表格的「輸入」欄打一組分數，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`highest` 這個函式應該怎麼改？
