# 長方形類別（傳統題）

用類別（class）寫一個長方形：建立時給寬和高，它會自己算面積、周長，還會回答自己是不是正方形。

## 規格

- 寫一個類別 `Rectangle`：
  - `__init__(self, width, height)`：把寬、高存成屬性 `self.width`、`self.height`。
  - `area(self)`：回傳面積。
  - `perimeter(self)`：回傳周長。
  - `is_square(self)`：寬高相等回傳 `True`，否則回傳 `False`。
- 主程式：輸入兩行，寬和高（正整數），建立一個 `Rectangle`，用它的方法印出三行：

```
面積 12
周長 14
不是正方形
```

  是正方形時第三行印 `是正方形`。
