# 電梯載重（傳統題）

電梯的載重上限是 **500 公斤**。乘客排成一列，依序上電梯。

## 規格

- 輸入：每行一位乘客的體重（整數，公斤），最後一行是 `結束`。
- 乘客照順序一個一個上電梯：
  - 這位上去以後，總重**不超過** 500 公斤（剛好 500 可以），他就上去。
  - 會超過的話，他不能上，**後面排隊的人也都不上了**（停止讀入）。
- 最後印出一行：`上了 N 人，總重 W 公斤`。

## 範例

| 輸入（每行一個） | 應該印出 |
|---|---|
| 60、75、結束 | 上了 2 人，總重 135 公斤 |
| 120、150、130、90、40、結束 | 上了 4 人，總重 490 公斤 |
| 200、300、1、結束 | 上了 2 人，總重 500 公斤 |
| 510、60、結束 | 上了 0 人，總重 0 公斤 |
| 結束 | 上了 0 人，總重 0 公斤 |

第 2 個範例：第 5 位 40 公斤，雖然 490 + 40 = 530 超過了；就算後面還有更輕的人，也不再上。
