# 質數判斷（抓錯題）

判斷一個數字是不是質數。

## 規格

- 輸入一行：0 以上的整數。
- 質數是 **2 以上**、只能被 1 和自己整除的整數。
- 是質數印 `是質數`，不是印 `不是質數`。

| 輸入 | 應該印出 |
|---|---|
| `7` | 是質數 |
| `15` | 不是質數 |

## 你的任務

AI 依照這份規格寫了下方的程式。上面的例子它都答對，可是它**有錯**。

這次**不用寫程式**，你要找出一個讓它印錯的輸入：

1. 讀程式。照著 `7` 和 `15`，在紙上算出 `range` 會產生哪些數字，一圈一圈追 `is_prime` 的變化。
2. 在表格的「輸入」欄打一組輸入，旁邊會自動出現這個程式印出什麼。
3. 在「正確應該印出」欄，依照規格寫下正確答案，按「檢查」。
4. 程式印的和正確答案不一樣，就抓到錯了。抓到以後，想想：`range` 的結束值和程式的開頭，各要怎麼改？
