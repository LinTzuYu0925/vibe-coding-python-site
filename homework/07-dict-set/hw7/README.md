# 通訊錄指令（黑箱題）

通訊錄程式用打字的方式操作，有四種指令：`新增 姓名 電話`、`修改 姓名 電話`、`查詢 姓名`、`刪除 姓名`。一開始通訊錄是空的。

輸入：

```
新增 小安 0911
查詢 小安
結束
```

印出：

```
已新增
0911
共 1 筆
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - **新增**一個已經有的人，會蓋掉舊電話嗎？印什麼？
   - **修改**、**查詢**、**刪除**一個沒有的人，各印什麼？
   - 刪除以後再查詢、再新增同一個人，會怎樣？
   - 指令打錯、少打欄位、多打欄位，會怎樣？空白行呢？
   - `Amy` 和 `amy` 算同一個人嗎？最後一行的筆數怎麼算？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
