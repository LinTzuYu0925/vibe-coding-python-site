# 工作天計算（傳統題）

專案經理想知道兩個日期之間有幾個工作天（週一到週五，不管國定假日）。**頭尾兩天都要算。**

## 規格

- 輸入兩行：開始日期、結束日期，格式 `YYYY-MM-DD`。
- 正常時印 `工作天 N 天`。
- 結束日期早於開始日期：印 `日期順序錯誤`。
- 日期不存在或格式不對：印 `日期錯誤`。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `2026-10-05`、`2026-10-09` | 工作天 5 天 |
| `2026-10-10`、`2026-10-11` | 工作天 0 天 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

單元 11 教過 `import datetime` 和 `.weekday()`（週一是 0，週日是 6）。下面這些寫法課程沒有教，這裡直接告訴你：

- `datetime.date.fromisoformat("2026-10-05")`：把文字變成日期；日期不對時會出現 `ValueError`。
- `d + datetime.timedelta(days=1)`：日期 `d` 的下一天。
- 日期可以直接比大小：`a <= b`。

不用 AI 也能完成。卡住時，先處理「開始和結束是同一天」，再用 `while` 一天一天往後走。
