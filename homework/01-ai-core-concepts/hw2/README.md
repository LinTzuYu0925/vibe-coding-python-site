# 電影票價（黑箱題）

電影院的售票機輸入年齡，回答票種和票價。

輸入：

```
25
```

印出：

```
全票 200
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的資料，找出下面問題的答案：
   - 總共有**幾種**票？各多少錢？
   - 幾歲開始不是兒童票？**剛好那一歲**算哪一種？
   - 幾歲開始是敬老票？**剛好那一歲**算哪一種？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI。可以貼到免費的 ChatGPT 或 Claude 網頁版。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。
