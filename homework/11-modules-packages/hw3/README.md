# 分數統計摘要（傳統題）

老師想看一次考試的統計摘要。這題請用標準函式庫的 `statistics`，不要自己寫公式。

## 規格

- 輸入：每行一個整數，最後一行是 `結束`。
- 至少有 2 個數字時，印出四行：

```
筆數 5
平均 74.0
中位數 80.0
標準差 18.17
```

  平均、中位數保留**一位**小數；標準差保留**兩位**小數，用 `statistics.stdev`。
- 只有 1 個數字時，標準差算不出來，第四行印 `標準差 無法計算`。
- 一個數字都沒有時，只印一行：`沒有資料`。

## 範例

| 輸入（每行一個） | 應該印出（用「／」隔開） |
|---|---|
| 50、90、80、60、90、結束 | 筆數 5／平均 74.0／中位數 80.0／標準差 18.17 |
| 88、結束 | 筆數 1／平均 88.0／中位數 88.0／標準差 無法計算 |
| 結束 | 沒有資料 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

會用到單元 11 的 `import statistics`（`statistics.mean`、`statistics.median`、`statistics.stdev`），還有單元 08 的 `while`、`.append()`、`if`。

不用 AI 也能完成。卡住時，先試試 `statistics.stdev([88])` 會出現什麼錯誤：這題可以用 `if` 先檢查，或用單元 10 的 `try`／`except` 接住，兩種都可以。
