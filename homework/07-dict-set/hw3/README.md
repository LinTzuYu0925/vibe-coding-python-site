# 宿舍查詢（傳統題）

宿舍管理員有一份住宿資料。輸入學號，程式要印出這位學生的姓名和房號。

| 學號 | 姓名 | 房號 |
|---|---|---|
| A01 | 小明 | 301 |
| A02 | 小華 | （還沒分配） |
| A03 | 小美 | 105 |
| A04 | 阿哲 | 512 |
| A05 | 阿芳 | （還沒分配） |

## 規格

- 輸入一行：學號。
- 印出兩行：`姓名 X` 和 `房號 Y`。
- 學生沒有房號：`Y` 印 `未分配`。
- 查不到這個學號：`X` 印 `查無此人`，`Y` 印 `未分配`。
- 學號要**完全一樣**才算查到。`a01` 和 `A01` 不同。

## 範例

| 輸入 | 應該印出（兩行，用「／」隔開） |
|---|---|
| `A01` | 姓名 小明／房號 301 |
| `A02` | 姓名 小華／房號 未分配 |
| `A99` | 姓名 查無此人／房號 未分配 |

## 你的任務

程式框是空的，從第一行開始自己寫：

1. 把表格寫成**巢狀 dict**：外層用學號當鍵，裡面放 `"name"`，有房號的才放 `"room"`。
2. 用 `input()` 讀學號，用 `.get(鍵, 查不到時的值)` 拿資料。這題**不用** `if`。
3. 按「檢查範例」。

不用 AI 也能完成。卡住時，先想：`.get()` 查不到學號時，第二個值放什麼，才能接著再 `.get("name", ...)`？
