# 信用卡號檢查（傳統題）

信用卡號的最後一碼是「檢查碼」，打錯一個數字時，網站馬上就能發現。它用的方法叫 Luhn 演算法。

## 規格

- 輸入一行：只有數字的字串，至少 1 碼。
- 從**最右邊**開始數，第 1、3、5… 碼不變；第 2、4、6… 碼乘以 2，乘完如果大於 9，就減 9。
- 全部加起來，能被 10 整除印 `有效`，否則印 `無效`。

例如 `346`，從右邊開始：`6` 不變、`4` 變成 8、`3` 不變。6 + 8 + 3 = 17，不能被 10 整除，所以無效。

## 範例

| 輸入 | 應該印出（多行用「／」隔開） |
|---|---|
| `79927398713` | 有效 |
| `79927398710` | 無效 |

## 你的任務

程式框是空的，從第一行開始自己寫，按「檢查範例」。

請**至少寫兩個函式**，例如 `double_digit(d)` 和 `is_valid(number)`，函式裡不要 `print`。網頁只檢查輸出，有沒有拆成函式要自己把關。

字串可以用 `for` 一個字一個字跑（單元 08），用 `int()` 轉成數字。要從右邊開始，可以用切片 `number[::-1]` 把字串反過來（這個寫法課程沒有教，它的結果就是倒過來的字串）。

不用 AI 也能完成。卡住時，先在紙上算一次範例，再寫 `double_digit`，確認它對了再往下。
