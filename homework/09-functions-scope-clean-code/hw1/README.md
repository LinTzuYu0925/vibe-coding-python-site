# 比賽排行榜（黑箱題）

比賽網站把參賽者的分數排成排行榜，只顯示前幾名。

輸入每行一位參賽者的「姓名 分數」，最後一行是 `結束`：

```
小安 70
小寶 85
小宇 60
小晴 55
結束
```

印出：

```
第 1 名 小寶 85
第 2 名 小安 70
第 3 名 小宇 60
```

## 你的任務

1. **試黑箱**：在「試試黑箱」輸入不同的分數，找出下面 6 個問題的答案：
   - 兩個人**同分**，名次一樣嗎？
   - 同分之後的**下一個人**是第幾名？（例如兩個人同分第 1 名，第三個人是第 2 名還是第 3 名？）
   - 同分的人，誰先印？和姓名有關，還是和輸入順序有關？
   - 第 3 名有**很多人同分**時，全部都印嗎？
   - 不到 3 個人時呢？**一個人都沒有**呢？
   - 分數 `100` 和 `95`、`9` 會排對嗎？
2. **寫規格**：把規則寫清楚，每條附一個「輸入 → 輸出」的例子。
3. **實作**：把規格和「給 AI 的格式說明」交給 AI，或自己寫。讀程式時，找找看 `key=` 比的是哪一欄（單元 09）。
4. **檢查**：把程式貼到下方，按「檢查範例」；再把你規格裡的例子輸入「試試黑箱」，按「也跑我的程式，比對」。

> 想想看：分數如果忘了轉成 `int`，`"100"` 和 `"95"` 比大小會發生什麼事？
